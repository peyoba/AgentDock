## 安全结论

- Keychain / PTY adapter 在 Phase 1 中只定义合同和 fail-fast unavailable 实现，不接入真实 native 能力。
- Profile metadata store 会丢弃意外传入的 `apiKey` 和完整 `env` 字段，只保存 Keychain 引用与非敏感 metadata。
- preload API 白名单只包含 `version`、`listProfiles`、`listWorkspaces`、`launchSession`、`listSessions`。
- preload 类型测试覆盖不暴露 `readSecret`、`getEnv`、`listEnvironment` 等完整 secret/env 读取方法。
