# AgentDock 项目文档

AgentDock 是一个可视化的 Claude / Codex 多配置终端启动器。

核心目标：

- 多个 Claude / Codex 终端可同时运行
- 每个终端使用独立 endpoint / API key
- API Profile 与工作目录解耦
- 多个 agent 可进入同一项目目录，也可进入不同目录
- Codex 使用独立 `CODEX_HOME` 隔离配置
- Claude 使用每终端环境变量隔离配置
