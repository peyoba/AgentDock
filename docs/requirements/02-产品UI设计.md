# AgentDock 产品 UI 设计

## 1. 信息架构

推荐做成 macOS 桌面 App 或菜单栏 App。

主界面包含：

```text
Dashboard   总览
Profiles    API 配置
Workspaces  工作目录
Launch      启动器
Sessions    运行会话
Settings    设置
```

## 2. Dashboard 首页

用途：快速启动常用组合，并查看当前运行状态。

```text
┌────────────────────────────────────────────┐
│ AgentDock                                  │
├────────────────────────────────────────────┤
│ Quick Launch                               │
│                                            │
│ [Claude AnyRouter A] [project-a] [Launch] │
│ [Codex OpenAI]      [project-a] [Launch]  │
│ [Claude Official]   [project-b] [Launch]  │
│                                            │
├────────────────────────────────────────────┤
│ Running Sessions                           │
│                                            │
│ 🟢 Claude AnyRouter A  project-a  23m      │
│ 🟢 Codex OpenAI        project-a  12m      │
│ ⚪ Claude Official     project-b  stopped  │
└────────────────────────────────────────────┘
```

核心操作：

- New Profile
- New Workspace
- Launch Session

用于管理 endpoint 和 API key。

```text
┌────────────────────────────────────────────┐
│ Profiles                         [+ Add]  │

│ Model: claude-sonnet-4                    │
│ Status: Tested OK                         │
│ [Edit] [Test] [Duplicate] [Delete]        │
├────────────────────────────────────────────┤
│ Codex - OpenAI Official                   │
│ https://api.openai.com/v1                 │
│ Model: gpt-5.4                            │
│ Status: Not tested                        │
│ [Edit] [Test] [Duplicate] [Delete]        │
└────────────────────────────────────────────┘
```

新增/编辑表单：

```text
Profile Name
Tool Type: Claude / Codex
Provider Type:
  - Anthropic Compatible
  - OpenAI Responses
  - OpenAI Chat Completions
  - Custom

Base URL
API Key
Default Model
Extra Environment Variables
Codex HOME Strategy:
  - Auto isolated
  - Custom path

[Test Connection]
[Save]
```

API key 展示方式：

```text
••••••••••••••••••
[Show] [Replace] [Remove]
```

## 5. Launch 页面

核心页面：选择 API Profile + Workspace + 启动模式。

```text
┌────────────────────────────────────────────┐
│ Launch New Agent Terminal                  │
├────────────────────────────────────────────┤
│ Tool/Profile                               │
│ [Claude - AnyRouter A              v]      │
│                                            │
│ Workspace                                  │
│ [project-a                         v]      │
│                                            │
│ Launch Mode                                │
│ (•) Shared directory                       │
│ ( ) New Git worktree                       │
│ ( ) Temporary copy                         │
│                                            │
│ Terminal                                   │
│ [iTerm2                            v]      │
│                                            │
│ Task Label                                 │
│ [Review payment module              ]      │
│                                            │
│ [Preview Environment] [Launch Terminal]    │
└────────────────────────────────────────────┘
```

Preview Environment 示例：

```text
Tool: Claude
Working Directory: /Users/peyoba/dev/project-a
Base URL: https://example.com
API Key: Stored in Keychain
Environment:
  ANTHROPIC_BASE_URL=https://example.com
  ANTHROPIC_AUTH_TOKEN=***
Command:
  cd /Users/peyoba/dev/project-a && claude
```


## 7. Settings 页面

配置项：

- 默认终端
- 默认启动模式
- AgentDock 数据目录
- Codex profiles 根目录
- 是否默认隐藏 API key
- 是否启动前检测同目录并发
- 是否启用 worktree 提示
- 导入/导出配置（不导出密钥，或需二次确认）
