# AgentDock UI 效果图

> 版本：v1  
> 风格：CC Switch 浅色卡片基底 + CCR 状态信息层级 + AgentDock 独有的 Launch / Sessions 结构。

> 说明：原 `docs/assets/mockups/` 原型图片已在 2026-07-05 项目清理第一阶段删除；本文件保留 UI 方向和版本演进说明。

## 设计重点

- 左侧导航：Home / Profiles / Workspaces / Launch / Sessions / Settings。
- 中间主区：Quick Launch，突出 Profile + Workspace + Terminal + Launch Mode 的组合启动。
- 右侧栏：Running Sessions，显示每个正在运行的终端实例。
- Profile 卡片：展示工具、endpoint、模型、key 状态和 Launch/Edit 操作。
- 共享目录提示：明确告诉用户多个 AI 会话在同一项目目录时的冲突风险。
- Preview Env：强调 endpoint/API key 只注入当前终端，不改全局配置。

## 下一步可调整方向

- 是否保留右侧 Sessions 常驻栏。
- 是否改成更原生 macOS Settings 风格。
- 是否增加深色版本。
- 是否把 Launch 组合器做成首页主操作，还是独立页面主操作。

## 中文界面版本 v1

说明：这一版将主要导航、按钮、说明文字、状态提示都改成中文，更适合作为中文用户的默认界面方向。

## 中文界面版本 v2：简洁内嵌终端工作台

说明：这一版去掉复杂 Dashboard，采用更简洁的内嵌终端工作台结构：顶部只保留会话启动栏，中间是终端标签页和终端主体，右侧只显示当前会话的必要信息与操作。

## 中文界面版本 v3：极简终端优先

说明：这一版接受“终端优先”的改版方向：去掉左侧常驻导航，顶部只保留核心启动条，中间最大化终端区域，会话详情改为浮层/抽屉。

## API 配置界面 v1

说明：API 配置页采用左侧配置列表 + 右侧编辑表单。重点展示 endpoint、默认模型、协议类型、API Key 钥匙串保存、环境变量预览和连接测试。

## API 配置界面 v2：按工具类型分类

说明：参考 CC Switch，将 API 配置按工具类型分类：Claude / Codex / Gemini / OpenCode / 全部。左侧只显示当前工具类型下的配置，右侧表单根据工具类型显示对应字段。

## 中文界面版本 v3b：会话详情收起状态

说明：右侧“当前会话”默认收起，通过标签栏按钮或右侧把手展开，避免遮挡终端主体。
